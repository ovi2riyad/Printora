# Third-party components

Printora itself is copyright © 2026 Riyad Ahmed Ovi and licensed under MIT (see `LICENSE`). This does not relicense third-party libraries, model weights or imported user content. Complete payloads ship the project license, LGPL/GPL texts, model/PDFium licenses and wheel-supplied notices in `licenses/`; retain that folder when redistributing. Qt/PySide6 and Qt PDF use their LGPLv3 option. Compatible replacement libraries and debugging modifications are permitted; see [component source/build links](licenses/README.md).

The application uses Python (PSF), PySide6/Qt (LGPLv3/GPLv3/commercial terms; this application uses dynamically linked libraries), Pillow (HPND), OpenCV (Apache-2.0), ONNX Runtime (MIT), NumPy (BSD-3-Clause), and ReportLab (BSD). Development tools include pytest, pypdf, and PyInstaller. Their installed distributions carry the authoritative licenses. Retain bundled license files when redistributing the executable folder.

PDF review/direct printing additionally uses the official `PySide6-PDF` package (Qt PDF/Qt PDF Widgets and PDFium). Qt 6.12 distributes this separately from Essentials; see the [official Qt release description](https://www.qt.io/blog/qt-for-python-release-6.12-is-here) and [Qt PDF licensing and attributions](https://doc.qt.io/qt-6/qtpdf-index.html). Retain the component notices supplied with those binaries; this overview is not a replacement for them. Scanner/printer integration uses Windows WIA/PowerShell, Qt Print Support and installed system drivers. No proprietary manufacturer driver or TWAIN DSM is bundled.

The `u2net_human_seg.onnx` portrait model and optional `u2netp.onnx` lightweight fallback come from the [rembg project release](https://github.com/danielgatis/rembg/releases/tag/v0.0.0). U²-Net originates from [xuebinqin/U-2-Net](https://github.com/xuebinqin/U-2-Net) (Apache-2.0). Model weights are excluded from the Git source repository. Settings and the installer can download them explicitly; a Windows application build bundles the installed portrait model when available at build time. See the upstream projects for model details and licenses.

Synthetic images are used in the public automated test suite. Private studio demonstration images and historical downloaded development fixtures are not distributed with the source or installer.

Windows Setup is built with [Inno Setup](https://jrsoftware.org/isinfo.php), a separate build tool whose installer engine is included in the generated Setup. The build helper pins official Inno Setup 7.1.1 x64 and verifies SHA-256 `8a5a6711c3766a6e5fb74f280ba0e3551e719ce94538d901fdbd1f8f9920b3f0`. The full compiler installation remains local and is not a Python runtime dependency. See the [upstream license](https://github.com/jrsoftware/issrc/blob/main/license.txt) for redistribution terms. Retain engine notices generated by the compiler.

QR features use the existing OpenCV dependency. Text PDFs can embed a locally installed Windows font for labels; no Windows font file is copied into the source or application package. Complex-script layout is not guaranteed. `assets/printora.svg` is an original code-native project icon; its ICO is generated at build time.

The TWAIN adapter is project interoperability code using documented structures/messages with the installed system DSM; see the [TWAIN standard header](https://github.com/twain/twain-dsm/blob/master/TWAIN_DSM/src/twain.h). No proprietary driver, native DSM or Windows system DLL is copied into the product. Native discovery/capability checks do not certify physical transfers.
